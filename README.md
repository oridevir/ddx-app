# אבחנה מבדלת: חלון עזר לרופא

הרופא מקליד תסמין ומקבל את האבחנה המבדלת, בחלון צף שנשאר מעל הרשומה הרפואית.

## קבצים
- `index.html`: האפליקציה, קובץ אחד עם המאגר בתוכו. זה הקובץ שנפתח בדפדפן.
- `ddx-data.json`: המאגר עצמו. כאן מעדכנים תוכן.
- `ddx.src.html`: התבנית שממנה האפליקציה נבנית.
- `sw.js`: מטמון לעבודה בלי אינטרנט.
- `ddx.html`: הפניה לכתובת החדשה, בשביל קישורים ישנים.
- `build.py`: מחבר את התבנית והמאגר לקובץ `index.html`. מריצים `python3 build.py` אחרי כל שינוי.

## כתובת
https://ddx.drdevir.com

## תוכנת חלונות
- `desktop/`: תוכנה קטנה שמציגה את האפליקציה בחלון שנשאר מעל כל החלונות, צמוד לפינה השמאלית התחתונה. המקש F9 מעלים ומחזיר אותו.
- התוכנה נטענת מהאתר (`?shell=1`), כך שכל שינוי באתר מגיע אליה לבד.
